# Sources and implementation provenance

- [CESNET/GPUJPEG](https://github.com/CESNET/GPUJPEG), upstream base `78e5eee3f75e0a2a2e6c1409000ac05d679b4af8`. Existing block lists, quantized layout, Huffman tables, stream handling and IDCT/output stages are reused. Existing project licenses are retained.
- [REA](https://github.com/morluto/rea), version 6.7.0, with Rizin. The [nvJPEG analysis](archive/nvjpeg-no-restart/analysis.md) records commands, Evidence IDs, DLL identity, static observations and runtime corroboration. The [initial Fastvideo report](archive/fast-jpeg-investigation.md) and [decoder analysis](archive/decoder-analysis.md) distinguish observed native/runtime behavior from inference. Vendor/version-specific findings should not be generalized to every release.
- Installed NVIDIA CUDA 13.4 nvJPEG, DLL SHA-256 `957bb73818e62883ac4bfc0aa15204bba5e341a8f7964a11b0289742df4e0da2`. Public API reference: [nvJPEG encoder documentation](https://docs.nvidia.com/cuda/nvjpeg/index.html). Public-API harnesses and the transfer-inclusive methodology are retained; no proprietary implementation is redistributed. Parallel block symbol generation, scans, bit assembly and stuffing guided the independently written encoder.
- [Weissenberger and Schmidt, Accelerating JPEG Decompression on GPUs](https://arxiv.org/abs/2111.09219). Conceptual basis: speculative entropy decoding, boundary synchronization and scan-based reconstruction. This branch independently implements a balanced reconciliation hierarchy with an exact-state correctness argument and an independently developed proven-zero-region shortcut.
- [jpeggpu](https://github.com/nolmoonen/jpeggpu), examined at `3ae7ac0dbc6e1b047abaa67badb6378baa7d39cb`. Repository metadata/README supplied context. It is GPLv3; its implementation source was not imported, and it was not benchmarked here.
- JPEG baseline sequential syntax: [ITU-T T.81](https://www.itu.int/rec/T-REC-T.81). Existing GPUJPEG references and table definitions also remain in the upstream README.

The current implementation notes, reports, transfer captures and validation records are original investigation documentation. Full third-party publications and vendor implementation artifacts are linked or identified rather than copied. The tested Fastvideo package was SDK 0.21.1.0 Windows x64 trial; findings concern that tested executable and inputs. The original [comparison report](archive/original-comparison/report.md) provides the measured boundary and qualifications.
